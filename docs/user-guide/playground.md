# Workflow Builder (playground)

The click-through builder, running right here on the docs site — assemble a workflow
step by step and **copy or download** the resulting `input.yaml`. The forms are
rendered from the same live schema the loader validates with. Running validation,
saving files, and editing templates need the local [`chemrefine gui`](gui.md).
